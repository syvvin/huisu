# 使用说明

## 启动与片库

安装版直接运行桌面窗口；源码运行 `python packaging/launcher.py` 或 `.\run.ps1`。应用默认扫描片库目录下的 `part.json`，片库按 **主题 → 章节 → Part** 分层。片库目录可在设置里修改，保存后自动重新扫描。

## 预习

打开某个 Part 的「预习」：

- 按 CEFR 级别筛选生词候选，支持 A1–C2 多选，默认 B1 + B2。
- 自动排除已收录词、功能词和人名。
- 每行显示 CEFR 徽标、释义和本集第一句原句。
- 点单词可先看词典；点 ＋ 收进本集，同时保存当前句作为来源。

级别在预习页顶部或设置里选择，保存后所有 Part 共用。

## 观看

- 左边是视频，右边是逐句双语字幕；当前句高亮并自动滚动。
- 拖动中间分隔线可调整视频/字幕宽度，比例会记住。
- 点字幕里的单词，右侧打开词典；查词时视频与字幕整体让位，三栏并存。
- 点句子跳转到对应时间；`↻` 可单句循环 ×3 / ∞。
- 字幕菜单支持双语 / 仅英文 / 仅中文 / 关闭，以及「遮住中文」。
- 画面上的字幕可以拖动位置；字幕样式分英文、中文、通用三组，可调字号、颜色、背景、字重、字体、阴影和对齐。
- 「⋯」菜单可调 0.75×–1.5× 速度和静音；播放位置自动保存。
- 视频全屏时标题栏会隐藏，按 Esc 退出。

### 查词与来源

词典面板支持多个引擎，结果按引擎分卡片。面板内还有：

- **我的备注**：每个词独立保存，可在设置里控制是否显示。
- **来源句子**：同一个词的多个来源会归在一起，可播放本集视频并回到本句，或跳到视频。
- 已收录的词再次遇到时，可点「＋ 收录这句话」把新句子加入同一条词目。
- 外链可跳转必应 / 欧陆 / 有道，适合游戏自造词。

## 复习

「待温习」按记忆曲线给出到期词条，也可以在词库选择「全部词」复习：

- 卡片先显示语境填空或单词，空格显示释义。
- 三个评价：`1 忘了 / 2 模糊 / 3 记得`。
- 可重听原句、查看详细信息、跳过、退出或完成后重跑。
- 复习记录、掌握度和下次到期时间都会写回本地数据。

## 词库

- 支持全部 / 待温习 / 新词 / 已掌握 / 已忽略筛选，以及搜索。
- 单词、释义、5 格掌握度、到期时间都在一行内。
- **忽略**会移出复习和待温习统计，但保留词条、来源、备注和进度；**删除**才会永久移除。
- 支持批量选择和导出 CSV。

## 资源提取

侧栏「资源」启动内置 UTTU 提取器：

1. 展开分类 / 章节，勾选需要提取的 Part；也可以勾选整个章节或分类。
2. 选择分辨率（默认 1080p），点「开始提取」。
3. 提取完成后点「重新扫描片库」，Part 会出现在片库。

说明：

- 勾选只在当前页面会话有效；关闭应用或重新进入资源页会清空，不会恢复上次选择。
- 每个 Part 会输出独立视频、英文 SRT、中文 SRT 和双语 SRT。
- 同一录像只需要下载一次完整源；之后同分辨率的 Part 直接从缓存裁切。不同分辨率分别缓存。
- 资源页会显示源视频缓存大小和完整 / 未完成数量，可清理应用自己的缓存；旧版 `uttu-extractor/data/cache/media` 会被自动发现并复用。
- 提取需要联网访问 UTTU 站点和 YouTube。

## 设置

- **外观**：暗色 / 亮色主题；标题栏和字幕颜色会跟随。
- **查词面板**：调整词典、备注、来源句子的顺序；选择每个词典要显示的内容；开关备注显示。
- **片库目录**：修改输出目录并重新扫描。
- **发音**：英音 / 美音，是否自动播放。
- **数据**：所有学习记录保存在本机 `state.json`，不上传服务器。

## 快捷键

### 观看

| 键 | 功能 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `← / →` | 上一句 / 下一句 |
| `L` | 切换单句循环 |
| `R` | 重播当前句 |
| `F` | 全屏 |
| `Esc` | 退出全屏 / 关闭词典 |

### 复习

| 键 | 功能 |
| --- | --- |
| `空格` | 显示释义 |
| `1 / 2 / 3` | 忘了 / 模糊 / 记得 |
| `S` | 跳过 |
| `R` | 重听原句 |
| `P` | 发音 |

## 数据位置

- 源码运行：仓库下 `data/state.json`。
- 安装版：`%LOCALAPPDATA%\回溯\data\state.json`。
- 片库默认：`%USERPROFILE%\Videos\回溯`，可在设置中修改。
- `vocab.db` 是可重建的运行时索引；学习记录以 `state.json` 为准。

## 常见问题

- **查词失败**：有道 / Free Dictionary 是公开接口，可能限流；应用会退回本地 ECDICT、CEFR 和缓存。
- **提取没有输出**：确认片库目录设置正确，并检查网络是否能访问 UTTU 与 YouTube。
- **端口被占用**：关闭旧实例后重开即可；应用会在退出时释放本地 8766 端口。
- **资源提取器勾选消失**：这是预期行为，勾选不跨会话保存。
